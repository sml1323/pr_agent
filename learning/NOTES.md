# 작업 노트

## 학습자에 대해

- 파이썬은 안다. **LLM API는 처음.** 첫 `parse()` 호출을 아직 안 해봤다
- 백지에서 시작하는 걸 어려워한다 — "머보고 구현해? 아무 소스 없이?"
  → 뼈대·배선은 주고 **판단 자리만 `TODO(human)`**으로 비우는 형태가 맞았다 ([ADR 0002](../docs/adr/0002-implementation-mode.md) 개정)
- 전체 그림 없이 세부부터 들어가면 헤맨다. **파트 시작 전에 "이게 전체의 어디인지"를 먼저** 말해야 한다
- 메타인지를 중요하게 여긴다 — 본인이 먼저 "선행 학습하고 진행하면 메타인지가 잘 될 것 같다"고 제안했다

## 진행 규칙

- 한 번에 파일 하나, `TODO(human)` 2~3개까지
- 결정은 **저스트-인-타임** — 필요해지기 직전에. `docs/CURRENT.md`의 "결정을 미룬 것" 표가 시점을 관리
- 검증은 말이 아니라 **실행 결과**로. "돌아갑니다" 대신 출력을 보여준다
- 답을 바로 주지 않는다 (30분 룰). 단 요청하면 준다

## 이 워크스페이스에 대해

- teach 워크스페이스를 프로젝트 루트가 아니라 `learning/`에 뒀다.
  루트에 `lessons/`, `reference/`가 흩어지면 `backend/`, `docs/`와 섞여 지저분해서
- `study/` 디렉토리는 `/study` 스킬이 만든 별개 세션. 둘 중 하나로 정리 필요
- 미션이 이미 `docs/`에 상세히 문서화돼 있어 인터뷰 없이 `MISSION.md`를 추출했다.
  **사용자 확인 필요** — 특히 "Success looks like" 항목
