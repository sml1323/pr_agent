# ADR 0002 — 코드는 사람이 직접 작성한다

**날짜**: 2026-07-28
**상태**: 확정
**맥락**: [ADR 0001](0001-project-setup.md) D1에서 "하네스는 직접"을 정했지만, **코드를 누가 치는가**는 따로 정하지 않았다. 그게 별개 결정이라는 걸 놓쳤다.

---

## 결정

**코드는 사람이 직접 타이핑한다.** 코딩 에이전트에게 구현을 시키지 않는다.

## 영상은 반대로 간다

영상 화자는 코드를 직접 치지 않는다. Claude Code 같은 터미널 에이전트에게 시키고, 자신은 설계·방향·검증·이해에 집중한다. 그게 영상 전체의 논지이기도 하다 — **하네스가 코드 품질을 결정한다** [02:19:28].

그리고 그건 **엉성한 방식이 아니다.** `DONE.md` 고정 [02:02:24], 마일스톤당 데모 명령, 별도 세션 독립 검증 [02:37:06], 이해도 퀴즈 [03:00:45]로 조여놓고 시킨다. 실제로 그 장치들이 값어치를 증명했다 — 빌더가 완료를 선언한 M1에서 독립 검증자가 500 크래시를 잡아냈다 [02:38:39].

**그럼에도 다르게 가는 이유는 목표가 다르기 때문이다.**

## 근거

[ADR 0001](0001-project-setup.md) D4에서 학습 비중을 **설계 사고 60% / 완성 30% / 하네스 10%**로 정했다. 이 비중에서는 에이전트 구현이 맞지 않는다.

| | 에이전트가 구현 | 사람이 구현 |
|---|---|---|
| 배우는 것 | AI를 부리는 법, 검증 설계 | 설계가 코드에서 어떻게 저항하는지 |
| M8까지 | 며칠 | 몇 주 |
| 막혔을 때 | 에이전트가 뚫음 → 내가 못 배움 | 내가 뚫음 → **그게 배움** |
| 이해도 체크 | 필수 (안 하면 이해 못 한 코드가 쌓임) | 대체로 자동 |

결정적인 건 마지막 줄이다. **설계는 코드에서 저항할 때 이해된다.** M2의 `TRUNCATE`가 DELETE 트리거를 우회하는 함정 [03:02:54]이나 pgvector 차원 불일치 [03:03:59] 같은 건, 읽어서 아는 것과 직접 부딪혀서 아는 게 다르다.

하네스 10%라는 비중도 이 결정과 일관된다 — 에이전트 운용법을 배우는 게 이 프로젝트의 주목적이 아니다.

## Claude의 역할

**코드를 대신 쓰지 않는다.** 대신:

1. **브리핑** — 마일스톤 시작 전 "뭘 만드는지 / 왜 그 모양인지 / 어떤 순서로"
2. **막혔을 때 힌트** — 답을 바로 주지 않는다. 30분 룰 (아래)
3. **독립 검증** — 하네스의 ④단계. 새 세션에서 내 코드를 공격
4. **개념 설명** — 라이브러리, 프로토콜, 용어

예외로 코드를 받아도 되는 것: 순수 보일러플레이트(`.env.example`, `pyproject.toml`, 마이그레이션 실행 스크립트 등). 배울 게 없는 것들.

## 30분 룰

막히면 바로 답을 받지 않는다.

```
어디서 시작할지 모름   → "이거 어떤 순서로 접근해?"
에러가 남              → "이 에러 무슨 뜻이야?" (코드 말고 원인)
API를 모름             → "pgvector 코사인 유사도 연산자 뭐야?"
설계가 헷갈림          → "왜 여기서 X가 아니라 Y지?"
30분 이상 막힘         → "힌트 줘 — 답 말고" → 그래도 안 되면 답
```

**바로 답을 받으면 그 부분은 안 배운 것.**

## 독립 검증의 의미가 바뀐다

에이전트가 구현할 때 독립 검증의 목적은 "이 코드를 사람이 이해했나"였다. **내가 직접 짜면 이해는 이미 됐고, 대신 내가 못 본 구멍을 찾는 게 목적이 된다.**

자기 코드의 맹점은 자기가 제일 못 본다. 그래서 이 단계는 오히려 **더** 중요해진다. 절차는 그대로 — 새 세션, 구현 세션 대화 절대 안 줌, "돌아가나"가 아니라 "어떤 불변식이 위험한가"로 질문 [02:57:57].

## 받아들이는 비용

- **M8까지 몇 주 걸린다.** 며칠이 아니라. 이건 알고 시작하는 것.
- **AI 하네스 운용 경험은 덜 쌓인다.** 대신 하네스 자체(`DONE.md`, 독립 검증, 이해도 체크)는 그대로 굴리므로 뼈대는 익힌다.

## 되돌리기

M0~M2를 직접 쳐본 뒤, 배움 대비 속도가 나쁘다고 판단되면 뒤쪽 마일스톤(특히 M3·M4 같은 배관 작업)을 에이전트에게 넘길 수 있다. 그때는 이 ADR을 개정하고 `WORKFLOW.md`도 같이 고친다.

**설계 판단이 핵심인 마일스톤(M0 Finding 스키마 / M2 DB 불변식 / M7 리트리벌 / M8 게이트)은 넘기지 않는다.**

## 영향받는 문서

- `docs/WORKFLOW.md` — 세션 흐름을 5단계로 재작성 (①브리핑 ②내가 구현 ③자가검증 ④독립검증 ⑤이해도+마무리)
- `docs/DONE.md` — 3단 완료 판정은 그대로 유효

## 개정 (2026-07-28, M0 착수 중) — 스캐폴드 + TODO(human)

**바뀐 것**: "Claude는 코드를 전혀 쓰지 않는다" → **"Claude가 뼈대·배선·보일러플레이트를 쓰고, 설계 판단이 들어가는 자리만 `TODO(human)`으로 비운다."**

**왜**: M0 `schema.py`에서 막혔다. 사용자 말 그대로 — *"머보고 구현해? 아무 소스 없이?"*

그리고 그건 정확한 관찰이었다. **베낄 원본이 실제로 없다.** 영상은 3시간 중 2시간 43분을 설계에만 쓰고, 코드는 터미널 에이전트에게 시킨 뒤 워크스루만 한다 [02:43:58]. 화자가 타이핑하는 장면 자체가 없고, M0은 영상에 아예 존재하지 않는(이 프로젝트가 학습용으로 추가한) 마일스톤이다.

원래 ADR의 전제는 "설계는 코드에서 저항할 때 이해된다"였는데, **백지는 저항이 아니라 마찰**이다. 저항은 `TODO(human)` 자리에서 나온다 — 실제로 첫 시도에서 `confidence: float = Field(ge=0.6)`이 나왔고, 그게 M8 게이트의 `else` 분기를 통째로 죽인다는 걸 직접 돌려보고 알았다. 그게 목표하던 학습이다.

**지키는 것**: 학습 비중 설계 사고 60%([ADR 0001](0001-project-setup.md) D4)는 그대로. TODO 자리가 그 60%를 담는다.

**경계**: 한 번에 TODO 2~3개까지. 더 비우면 백지와 같아지고, 덜 비우면 받아쓰기가 된다.
비운 자리마다 **왜 이게 판단인지 + 틀리면 뭐가 깨지는지**를 주석으로 남기되 답은 쓰지 않는다.

**여전히 안 넘기는 것**: 설계 판단이 핵심인 마일스톤의 **판단 자체** — M0 Finding 스키마 / M2 DB 불변식 / M7 리트리벌 / M8 게이트. 뼈대는 받아도 그 안의 결정은 사람이 한다.

**운영 규칙은** [`CLAUDE.md`](../../CLAUDE.md)에 있다.

## 개정 (2026-08-25) — 구조도 판단이다: 구조 결정 카드

**바뀐 것**: "뼈대·배선 = Claude" 분류에서 **디렉토리·모듈 경계를 빼서 판단 쪽으로 옮긴다.**
새 파일·디렉토리·모듈 경계가 생기기 **직전**, Claude 는 스캐폴드 대신 **구조 결정 카드**를 먼저 내민다.

**왜**: M0~M5 를 지나며 사용자가 직접 짚었다 — *"디렉토리 구조, 코드 구조, 아키텍처적인 건
아무런 고민 없이 만들어주는 대로 했다."* 정확한 관찰이다. 스캐폴드는 구조 질문에
**이미 답한 채로 도착**한다 — 파일이 그 자리에 생기는 순간 "어디 살아야 하나"는 답변이 끝나 있다.
그래서 `TODO(human)` 이 값 수준 판단(필드 타입·게이트 조건)은 지켜도,
**구조 수준 판단은 그대로 샜다.** 설계 사고 60%(ADR 0001 D4)가 구조 층에서 새고 있었다.

**카드 형식** — 운영 규칙은 [`CLAUDE.md`](../../CLAUDE.md) 진행 순서 2.5:

- **결정** 한 줄 (예: `stats.py` 는 어디 사나)
- **후보 2~3 + 각각의 기준** — 열린 질문("구조를 설계하라") 금지. 후보 없으면 백지다
- **변경 리허설** — 미래 변경 시나리오 1~2개를 들이대 각 후보가 어떻게 버티나.
  노트북이 정의를 몬테카를로로 옮겨 검증하듯, 구조는 변경 리허설로 검증한다
- **틀리면 깨지는 것** — 순환 import, 복붙, 파일 이사 같은 구체적 증상

사용자가 고르고 **한 줄 근거**를 남긴다(`CURRENT.md` 결정표 또는 ADR). 그다음에야 스캐폴드.

**경계**: 답이 사실상 하나인 구조(관례가 정한 자리)에는 카드를 만들지 않는다 —
"판단이 안 갈리는 자리에 레슨을 붙이지 않는다"(`CLAUDE.md` 0)와 같은 규칙.
아니면 카드가 판단이 아니라 숙제가 된다.

**첫 적용**: M6-1 — `backend/eval/` 신설이 첫 실전이다. stats.py·grader.py·expected.yaml 이
어디 사나, 평가는 제품 코드인가 개발 도구인가.
